Семантичний
Атлас

Концептуальна карта термінів: системний перехід від UX-психології до технічних метаданих об'єктів мультимедійного видання.

UX Psychology

Когнітивна легкість

Стан, у якому користувач обробляє інформацію без надлишкових зусиль. Досягається через візуальну ієрархію та передбачувану навігацію.

Ментальна модель

Уявлення про структуру ресурсу, сформоване на основі аналізу існуючих порталів (напр. Wiki Loves Monuments).

Естетико-юзабільний ефект

Феномен, коли користувачі сприймають більш привабливий дизайн як більш функціональний та зручний.

Object Metadata

Семантичне ядро пам'ятки

Набір унікальних ідентифікаторів (геолокація, дата заснування, статус охорони), що описують культурний об'єкт.

Таксономія контенту

Деревоподібна система класифікації локацій за категоріями для точної фільтрації в інтерактивних модулях.

Дані реального часу

Інтеграція динамічних параметрів (відстань до об'єкта, доступність), що підвищують цінність мультимедійного контенту.

System Logic

Interactive Feedback

Миттєва відповідь системи на дії користувача (зміна кольору кнопки, анімація), реалізована через JavaScript.

JSON Schema

Стандартизований формат збереження даних, який дозволяє масштабувати кількість пам'яток без зміни програмного коду.

DOM Маніпуляції

Процес динамічного оновлення вмісту сторінки на основі вибору користувача без перезавантаження всього документа.
